# Computer Hardware and Software — Notes

## 1. Introduction to a Computer

A **computer** is an electronic device that accepts data as input, processes it according to instructions, stores it, and produces information as output.

### Basic Functions
1. **Input:** Receives data and instructions.
2. **Processing:** Performs calculations and logical operations.
3. **Storage:** Saves data and programs.
4. **Output:** Presents the processed information.

### IPO Cycle
**Input → Processing → Output** (with storage used to save data and results).

---

## 2. Computer Hardware

**Hardware** refers to the physical parts of a computer that can be seen and touched.

### Main Hardware Components

- **Input Devices:** Used to enter data. Examples: Keyboard, Mouse, Scanner, Microphone, Webcam.
- **Output Devices:** Display or produce results. Examples: Monitor, Printer, Speakers, Projector.
- **Processing Devices:** The CPU processes instructions and controls computer operations.
- **Storage Devices:** Store data and programs. Examples: HDD, SSD, USB Flash Drive, Memory Card, Optical Disc.

### Central Processing Unit (CPU)

The **CPU** is often called the brain of the computer. Its main parts are:

- **Control Unit (CU):** Directs and coordinates computer operations.
- **Arithmetic Logic Unit (ALU):** Performs arithmetic calculations and logical comparisons.
- **Registers:** Very small, fast storage locations inside the CPU that temporarily hold data and instructions.

### Primary Memory

Primary memory is directly accessible by the CPU.

- **RAM (Random Access Memory):** Temporary, volatile memory. Its contents are normally lost when power is switched off.
- **ROM (Read Only Memory):** Non-volatile memory that retains its contents without power and stores essential instructions.

### Secondary Storage

Secondary storage keeps data for long-term use.

- **HDD:** Uses magnetic disks to store data.
- **SSD:** Uses flash memory; generally faster and has no moving parts.
- **USB Flash Drive:** Portable flash storage.
- **Optical Disc:** Uses laser technology, for example CDs and DVDs.

### Other Hardware

- **Motherboard:** Main circuit board connecting computer components.
- **Power Supply Unit (PSU):** Supplies electrical power to components.
- **Graphics Processing Unit (GPU):** Processes graphics and parallel computing tasks.
- **Network Interface Card (NIC):** Connects a computer to a network.

---

## 3. Computer Software

**Software** is a collection of programs and instructions that tell a computer what to do. Software cannot be physically touched.

### Types of Software

### A. System Software

System software manages computer hardware and provides a platform for application programs.

- **Operating System:** Manages memory, files, processes, devices, and user interaction. Examples: Windows, Linux, macOS, Android.
- **Device Drivers:** Help the operating system communicate with hardware devices.
- **Utility Programs:** Help maintain, protect, and optimise a computer. Examples: Antivirus tools, Backup tools, Disk Cleanup utilities.
- **Language Translators:** Convert programs into a form the computer can execute. Examples: Compiler, Interpreter, Assembler.

### B. Application Software

Application software helps users perform specific tasks.

- **General-Purpose:** Word processors, spreadsheets, presentation software, web browsers.
- **Special-Purpose/Customised:** Payroll, billing, inventory, school-management, and hospital-management systems.

Examples include Microsoft Word, LibreOffice, Google Chrome, and VLC Media Player.

### C. Programming Software

Tools used to create, test, and maintain programs.

Examples: Code editors, Compilers, Interpreters, and Debuggers.

---

## 4. Difference Between Hardware and Software

| Hardware | Software |
|---|---|
| Physical components of a computer. | Programs and instructions. |
| Can be seen and touched. | Cannot be physically touched. |
| Manufactured from electronic and other physical materials. | Developed by writing and organising code. |
| Can be damaged physically. | Can be corrupted, deleted, or affected by malware. |
| Examples: Keyboard, Monitor, CPU, RAM. | Examples: Windows, Linux, Browser, Word Processor. |

**Important:** Hardware and software depend on each other. Hardware needs software instructions to perform useful tasks, while software needs hardware to run.

---

## 5. Difference Between RAM and ROM

| RAM | ROM |
|---|---|
| Volatile memory. | Non-volatile memory. |
| Used for currently running programs and data. | Stores firmware and essential instructions. |
| Usually can be read and written. | Typically read-mostly; some types can be rewritten. |
| Contents are normally lost when power is off. | Retains contents without power. |

---

## 6. Operating System

An **Operating System (OS)** is system software that manages the computer's resources and provides an interface between the user, applications, and hardware.

### Main Functions

1. **Process Management:** Manages running programs.
2. **Memory Management:** Allocates and frees main memory.
3. **File Management:** Organises files and folders.
4. **Device Management:** Controls input and output devices.
5. **Security:** Helps protect data and control access.
6. **User Interface:** Allows users to interact with the computer.

### Types of Operating Systems

- **Single-User OS:** Designed primarily for one user at a time.
- **Multi-User OS:** Allows multiple users to use system resources.
- **Multitasking OS:** Runs multiple tasks seemingly at the same time.
- **Real-Time OS:** Responds to events within defined time limits.
- **Network OS:** Provides services and resource management across a network.

---

## 7. How Hardware and Software Work Together

1. The user enters data using an input device.
2. The operating system and application software manage the task.
3. The CPU processes instructions, using RAM for temporary working data.
4. The result is sent to an output device or saved to storage.

**Example:** When typing a document, the keyboard sends input, word-processing software handles the text, the CPU processes instructions, RAM holds working data, and the monitor displays the document. The file can then be saved to an SSD or HDD.

---

## 8. Basic Computer Terminology

- **Data:** Raw facts and figures.
- **Information:** Processed data that is meaningful.
- **Program:** A set of instructions for a computer.
- **File:** A named collection of stored data.
- **Folder:** A container used to organise files.
- **Bit:** The smallest unit of digital data, either 0 or 1.
- **Byte:** A group of 8 bits.
- **Booting:** The process of starting a computer and loading its operating system.
- **Peripheral:** An external or additional device connected to a computer.

---

## 9. Advantages and Limitations of Computers

### Advantages

- High speed and accuracy when correctly programmed.
- Large storage capacity.
- Automation of repetitive tasks.
- Easy communication and access to information.
- Useful in education, business, science, healthcare, and entertainment.

### Limitations

- Requires electricity or another power source.
- Depends on correct instructions and data.
- Can be affected by viruses and other security threats.
- Hardware and software need maintenance.
- Cannot independently replace human judgement and understanding.
