# OPERATING SYSTEM (OS) – COMPLETE NOTES

## 1. Introduction to Operating System

An Operating System (OS) is system software that acts as an interface between the user and computer hardware. It manages all the resources of a computer and allows users to run different applications.

**Examples:**
- Windows
- Linux
- macOS
- Android
- iOS
- UNIX

### Definition
An Operating System is a collection of programs that manages computer hardware and software resources and provides services to computer programs.

## 2. Functions of Operating System

The main functions of an operating system are:

1. **Process Management:** Manages the execution of different programs.
2. **Memory Management:** Allocates and deallocates memory to programs.
3. **File Management:** Creates, deletes, stores and organizes files.
4. **Device Management:** Controls input and output devices such as keyboards, printers and monitors.
5. **Security Management:** Protects the computer from unauthorized access.
6. **User Interface:** Provides an interface between users and computers.
7. **Resource Management:** Manages CPU, memory and other resources.
8. **Error Detection:** Detects and handles system errors.

## 3. Types of Operating System

### 1. Batch Operating System
A batch operating system executes a group of similar jobs together without direct interaction with the user.

Example: Early IBM mainframe systems.

### 2. Time-Sharing Operating System
It allows multiple users to use the computer system at the same time by sharing CPU time.

Example: UNIX.

### 3. Multiprogramming Operating System
It allows multiple programs to stay in memory and share CPU resources.

Example: UNIX and modern operating systems.

### 4. Multitasking Operating System
It allows users to run multiple applications simultaneously.

Example: Windows and macOS.

### 5. Multiprocessing Operating System
It uses two or more processors to execute multiple processes simultaneously.

Example: Linux and Windows.

### 6. Real-Time Operating System (RTOS)
It provides immediate responses to input or events within a specific time limit.

Examples: VxWorks, QNX.

### 7. Distributed Operating System
It manages multiple independent computers and makes them work together as a single system.

### 8. Network Operating System
It allows computers to communicate and share resources over a network.

Examples: Windows Server and Linux Server.

## 4. Components of Operating System

The major components of an operating system are:

1. **Kernel:** The core part of an operating system that manages hardware and system resources.
2. **Shell:** Provides an interface between the user and the operating system.
3. **File System:** Organizes and manages files and directories.
4. **Device Drivers:** Help the operating system communicate with hardware devices.
5. **System Utilities:** Perform maintenance and management tasks.

## 5. Process Management

A process is a program that is currently running or executing.

The operating system manages processes by:

- Creating processes.
- Scheduling processes.
- Terminating processes.
- Allocating CPU time.
- Managing process synchronization.

### Process States

The main process states are:

1. **New:** Process is being created.
2. **Ready:** Process is waiting for CPU execution.
3. **Running:** Process is being executed.
4. **Waiting:** Process is waiting for an event or resource.
5. **Terminated:** Process has completed execution.

## 6. Memory Management

Memory management is the process of controlling and coordinating computer memory.

Functions of memory management:

- Allocates memory to programs.
- Deallocates memory after execution.
- Keeps track of used and free memory.
- Protects the memory of different processes.
- Manages virtual memory.

### Types of Memory Management

1. Contiguous Memory Allocation
2. Paging
3. Segmentation
4. Virtual Memory

## 7. File Management

File management is the process of creating, storing, organizing and deleting files.

Functions include:

- Creating files.
- Deleting files.
- Renaming files.
- Reading and writing files.
- Managing folders and directories.
- Controlling file permissions.

## 8. Device Management

Device management controls all input and output devices connected to a computer.

Examples:
- Keyboard
- Mouse
- Printer
- Scanner
- Monitor
- Hard Disk

The operating system uses device drivers to communicate with these devices.

## 9. Advantages of Operating System

1. Makes computers easy to use.
2. Manages computer hardware efficiently.
3. Supports multitasking.
4. Provides security and protection.
5. Manages files and folders.
6. Controls input and output devices.
7. Helps run application software.
8. Provides an interface between users and hardware.

## 10. Disadvantages of Operating System

1. Some operating systems are expensive.
2. System failure can affect the entire computer.
3. Some operating systems require high hardware resources.
4. They may be vulnerable to viruses and malware.
5. Regular updates and maintenance may be required.

## 11. Difference Between System Software and Application Software

| System Software | Application Software |
|---|---|
| Controls computer hardware. | Performs specific user tasks. |
| Runs and manages the computer system. | Runs on top of system software. |
| Essential for computer operation. | Used according to user requirements. |
| Example: Windows, Linux. | Example: MS Word, Chrome. |

## 12. Difference Between GUI and CLI

| GUI | CLI |
|---|---|
| Graphical User Interface. | Command Line Interface. |
| Uses icons, menus and windows. | Uses text commands. |
| Easy for beginners. | Requires command knowledge. |
| Uses mouse and keyboard. | Mainly uses keyboard. |
| Example: Windows Desktop. | Example: Command Prompt. |

## 13. Examples of Popular Operating Systems

### Windows
Developed by Microsoft. It is widely used in personal computers and laptops.

### Linux
An open-source operating system known for its security, flexibility and stability.

### macOS
Developed by Apple for Mac computers.

### Android
A mobile operating system mainly used in smartphones and tablets.

### iOS
Apple's mobile operating system used in iPhones.

## 14. Booting

Booting is the process of starting a computer and loading the operating system into memory.

### Types of Booting

**1. Cold Booting:** Starting a computer from a completely powered-off state.

**2. Warm Booting:** Restarting a computer without completely switching off its power.

## 15. Conclusion

An operating system is an essential part of a computer system. It manages hardware and software resources and provides a user-friendly environment. Without an operating system, it would be difficult for users to interact with computer hardware and execute applications efficiently.
