# OPERATING SYSTEM INSTALLATION PROCEDURE

## 1. Introduction

Operating System Installation is the process of installing system software on a computer or laptop to make it ready for use. An operating system manages computer hardware and software and allows users to perform different tasks.

Examples of operating systems:
- Windows
- Linux
- macOS
- Ubuntu

## 2. Requirements for Installing an Operating System

Before installing an operating system, we need the following things:

1. A computer or laptop.
2. Bootable USB drive (minimum 8 GB recommended for Windows installation).
3. Operating System ISO file.
4. Internet connection (if required).
5. Backup of important data.
6. Sufficient storage space.
7. Product key or digital licence (if required).

## 3. Steps to Install an Operating System

### Step 1: Download the Operating System

First, download the operating system ISO file from its official website.

Examples:
- Windows from Microsoft.
- Ubuntu from Ubuntu's official website.
- Linux distributions from their official websites.

### Step 2: Create a Bootable USB Drive

1. Insert a USB drive into the computer.
2. Download a bootable USB creation tool such as Rufus.
3. Open Rufus.
4. Select the USB drive.
5. Select the downloaded ISO file.
6. Click on Start.
7. Wait until the bootable USB drive is created.

**Note:** Creating a bootable USB drive may erase all data stored on it.

### Step 3: Restart the Computer

1. Insert the bootable USB drive into the computer.
2. Restart the computer.
3. Press the Boot Menu key during startup.

Common Boot Menu keys:
- F12
- F9
- F8
- Esc
- F11

The key depends on the computer manufacturer.

### Step 4: Select the USB Drive

1. Open the Boot Menu.
2. Select the USB drive.
3. Press Enter.
4. The computer will start booting from the USB drive.

### Step 5: Start the Installation Process

After booting, the operating system installation screen will appear.

Select:
- Language
- Time and currency format
- Keyboard layout

Then click Next and select Install Now (for Windows).

### Step 6: Accept the Licence Agreement

1. Read the licence agreement.
2. Accept the terms and conditions.
3. Click Next.

### Step 7: Select Installation Type

There are two common installation options:

**1. Upgrade Installation:** Installs a newer version while attempting to keep existing files, settings and applications.

**2. Custom Installation:** Allows users to perform a fresh installation and select the disk partition.

### Step 8: Select Disk Partition

1. Select the hard disk or SSD partition.
2. Choose the partition where you want to install the operating system.
3. Format or delete partitions only if necessary and after backing up important data.
4. Click Next.

**Warning:** Formatting or deleting a partition can permanently erase its data.

### Step 9: Copying Installation Files

The installation process will begin.

The computer will:
- Copy installation files.
- Install system features.
- Install updates (if available).
- Configure hardware.
- Restart automatically.

### Step 10: Complete the Setup

After installation, configure the following settings:

1. Select your country or region.
2. Choose your keyboard layout.
3. Connect to the internet.
4. Create a user account.
5. Set a password.
6. Configure privacy settings.

### Step 11: Install Device Drivers

After installing the operating system, install the necessary drivers.

Examples:
- Graphics driver
- Audio driver
- Network driver
- Wi-Fi driver
- Bluetooth driver

### Step 12: Install Application Software

Finally, install the required application software.

Examples:
- Google Chrome
- MS Office
- VLC Media Player
- Antivirus software

## 4. Precautions During OS Installation

1. Always back up important data.
2. Use an official operating system ISO file.
3. Make sure the computer meets the minimum system requirements.
4. Keep the computer connected to power.
5. Do not remove the USB drive during installation.
6. Select the correct disk partition.
7. Avoid interrupting the installation process.

## 5. Advantages of Installing an Operating System

1. Makes the computer ready for use.
2. Provides a user-friendly interface.
3. Manages hardware and software resources.
4. Improves system performance when replacing a damaged or outdated installation.
5. Provides security features.
6. Allows users to install and run applications.

## 6. Conclusion

Operating System Installation is an important process that makes a computer functional and ready to use. By following the correct installation steps, users can successfully install an operating system and configure the computer for daily tasks.
